# Public permission register

This file is the public permission register referenced by §7 of `LICENSE`.
No permissions are recorded yet. The template below is not itself permission.

For each grant, record the asker, the deed, the material, the place where it
will be used, the decision date, and the exact scope and conditions of the
permission. Record each written request and decision here. Do not describe a request as
granted until written permission has actually been given. Silence is not
consent.

## Entry format

```text
### Permission — YYYY-MM-DD
- Asker:
- Deed:
- Material:
- Place:
- Scope and conditions:
- Written decision/reference:
```
